# Solicitud de reporte para MUSE

Copia y adapta cuenta/periodo. No transmite datos por sí sola.

```text
Quiero un reporte para Mister ADS. Usa únicamente la cuenta de Meta Ads que yo elija y autorice. Antes de leer confirma la cuenta y el periodo. No cambies campañas, presupuesto ni conexiones.

Entrega un archivo con una fila agregada por anuncio para el periodo completo, sin totales mezclados: IDs de campaña/conjunto/anuncio, gasto, impresiones, clics de enlace, leads y definición de lead. Incluye cuenta, moneda, zona horaria, fecha de extracción, ventana de atribución y criterio temporal de acciones si se conocen. Lo que no puedas leer queda null y se explica; no lo conviertas en cero.

Separa tus observaciones de los datos consultados y señala la fuente. No presentes compras atribuidas como cobros comerciales verificados. No incluyas credenciales ni datos personales de clientes. Si puedes usar el ejemplo de formato que adjunto, respétalo; si no, devuelve tu formato real y explica sus campos para normalizarlo después.

No programes tareas ni envíes el reporte a otro servicio. Adjunta el archivo o indica claramente si solo puedes entregar texto.
```
